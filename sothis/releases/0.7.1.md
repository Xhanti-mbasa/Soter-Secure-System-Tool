Sothis 0.7.1 is the optimized version of 0.7.0, retaining its everyday workflows and share-card features.

- Bounded provider caches share concurrent requests while unrelated providers can run independently.
- Offline listings read metadata without loading every stored file; existing downloads migrate to the new schema.
- Local PDF assets are 49.6% smaller and load only when needed.
- Share previews reuse drawing resources, bound photo dimensions and avoid repeated PNG encoding during slider changes.
- The APK is 6.9% smaller: 2,330,874 bytes compared with 2,502,906 bytes in 0.7.0.

Install the attached APK on Android 8.0 or later. VersionCode 9 and the unchanged package/development signing certificate allow an update over earlier compatible Sothis installations.

Validation: 73 Python tests, all seven shared browser suites, authenticated website checks, production Java compilation, startup regression, v2/v3 signature verification and comparison of all 55 packaged assets with source. Timing measurements use controlled readers, not real network/device benchmarks.

The same provider limits as 0.7.0 apply: structured Eastern Cape vacancies, official-site application handoffs, authorized CIPC access/imports and reviewed/manual municipal recipients. Physical installation, camera/location and receiving social apps still require device checks. The website has not been deployed to the production server.
