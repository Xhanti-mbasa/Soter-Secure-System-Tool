Sothis 0.7.2 corrects the shared Android and website dock and restores employment figures on share cards.

- Fixed 20 px icons and a single active-tab label: Home, Regions, Jobs or Profile. No overlapping labels. The dock retains accessible names for every tab.
- Removed on-screen Back and parent-directory buttons; Android Back and browser history retain the existing routes.
- Removed the floating Search control wherever a screen already owns an inline search. The four-tab dock is centred in that state.
- The dock hides when the keyboard opens, using Android window visibility and browser visual viewport signals, then returns when it closes.
- Employment share cards include the numeric metrics, definitions, reporting period and original source. Northern Cape retains 36.3% absorption and 28.7% official unemployment.

Install the attached APK on Android 8.0 or later. VersionCode 10 uses the same package and development signing certificate as 0.7.1, allowing a compatible update while retaining app data.
