Sothis 0.7.0 adds everyday workflows and customizable public share cards to the shared Android and self-hosted website interface.

- Home, Regions, Opportunities and a local Profile; Search stays separate and Explore retains research tools.
- News catch-up, likes/bookmarks, offline saves, local TXT/PDF/DOCX CV import and skill matching.
- Eastern Cape eRecruitment vacancy cards and reviewed official application handoffs.
- Civic report drafts with reviewed recipients, media attachments, MIME export and email-composer handoff.
- Long-press sharing with frosted glass, liquid glass or solid styles; local background photos, opacity/blur and square/portrait/story PNGs.

Install the attached APK on Android 8.0 or later. It retains the existing package and development signing certificate for compatible updates. Keep the original signing key for future versions.

Feature validation: 70 Python tests, seven shared browser suites, authenticated website flow, Java compilation, APK signature and packaged-asset checks. Physical installation, camera/location and delivery to social apps still need device verification.

Provider limits: structured vacancies currently cover Eastern Cape eRecruitment; other official sources use browser handoffs. CIPC requires authorized registry access/imports. Municipal recipients beyond the reviewed Cape Town contacts require manual review. Handoff does not mean an application/report was submitted. The website code is included; the production domain was not deployed.
