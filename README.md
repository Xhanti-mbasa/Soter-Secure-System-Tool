# Soter: Secure System Configuration Tool

## What is Soter?

Soter (Σωτήρ)—Greek for "savior" or "preserver"—automates hardened Linux workstation configuration for penetration testers. It provisions fresh or existing installs with network isolation, driver integrity, package management controls, and pre-configured security tools (VPN, browsers, messaging apps).

Soter is **not** an antivirus or SIEM system. It is an environment configuration and recovery tool with optional scanning capabilities. Use it to establish a known-good security baseline, not to detect active threats.
